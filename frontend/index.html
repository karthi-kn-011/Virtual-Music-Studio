Physical QWERTY Keyboard Mapping

You can perform any musical melody or polyphonic chord using your computer's physical keyboard:

Lower Chromatic Row (Natural White Keys):
A = C  |  S = D  |  D = E  |  F = F  |  G = G  |  H = A  |  J = B  |  K = C5  |  L = D5  |  ; = E5

Upper Chromatic Row (Black Accidentals #/b):
W = C#  |  E = D#  |  T = F#  |  Y = G#  |  U = A#  |  O = C#5  |  P = D#5

Octave & Performance Controls:
Z / X = Octave Down / Up
C / V = Velocity Decrease / Increase
Space = Sustain Pedal (hold or tap)
Escape = Silence all playing notes (Panic)

About & Instrument Licensing

Virtual Music Studio is a digital audio workstation built entirely with vanilla Web Audio API and modern JavaScript standards.
